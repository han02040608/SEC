# Sample Station Data

This folder contains example data for one hydrological station.

## Files

- `sample_station_data.csv`: sample records extracted from the station dataset

## Columns

- `date`: observation date
- `dayl(s)`: day length in seconds
- `prcp(mm/day)`: daily precipitation
- `srad(W/m2)`: shortwave radiation
- `swe(mm)`: snow water equivalent
- `tmax(C)`: daily maximum temperature
- `tmin(C)`: daily minimum temperature
- `vp(Pa)`: vapor pressure
- `OT`: observed target value used for runoff forecasting

## Notes

- The sample file contains 365 records.
- This subset is provided for format demonstration and repository example usage.
